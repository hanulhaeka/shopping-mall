# 요구사항 정의

# 회원

### 회원 가입

- 네비게이션 바에 있는 회원 가입 버튼을 통해 회원 가입 페이지로 이동
- 회원 가입 페이지에서 필요한 정보를 적고 회원 가입

### 로그인

- 네비게이션 바에 있는 로그인 버튼을 눌러 로그인 페이지로 이동
- 로그인 페이지에서 아이디와 비밀번호를 입력해 로그인

### 로그아웃

- 로그인 시 네비게이션 바에 로그아웃 버튼이 노출
- 해당 버튼을 눌러 로그아웃

### 권한

- 일반 회원과 관리자 두 가지로 권한이 구분
- 일반 회원은 상품 조회, 주문, 장바구니 도메인 관련 기능 사용 가능
- 관리자는 일반 회원이 사용 가능한 기능에서 상품 관리를 위해 상품 추가, 수정, 삭제가 가능
- 미인증 사용자는 상품 조회 관련 기능만 사용 가능

# 상품

### 상품 등록

- 관리자 권한 사용자가 상품을 등록할 수 있음
- 관리자 권한으로 로그인 시 상품 등록 버튼이 네비게이션 바에 노출
- 상품 등록 버튼을 통해 상품 등록 페이지로 이동하여 필요한 정보를 입력하여 상품 등록

### 상품 수정

- 관리자 권한으로 로그인 시 상품 목록 버튼이 있고 해당 버튼을 누르면 상품 목록 페이지로 이동
- 상품 목록 페이지에서 각 상품에 따라 수정 버튼이 있음
- 특정 상품의 수정 버튼을 누르면 상품 수정 페이지로 이동
- 상품 수정 페이지에서 수정할 정보를 수정한 후 상품 수정

### 상품 삭제

- 관리자 권한 로그인 시 네비게이션 바에 나오는 상품 목록 버튼을 눌러 상품 목록 페이지로 이동
- 상품 목록 페이지에 각 상품에 따라 삭제 버튼이 있음
- 상품 삭제 버튼을 누르면 해당 상품 상태를 삭제 상태로 변경

### 상품 목록 조회

#### 일반 사용자

- 쇼핑몰 메인 페이지가 상품 목록 페이지가 됨
- 상품 목록 페이지에서 일정 개수 만큼의 상품을 나누어서 페이지네이션으로 보여줌

#### 관리자

- 관리자는 상품 수정 또는 삭제와 현재 쇼핑몰에 등록된 상품 확인을 위해 따로 상품 목록 페이지가 있음
- 해당 상품 목록 페이지는 관리자 권한으로 로그인 시 조회 가능

### 상품 상세 조회

- 상품 목록 페이지 또는 장바구니에 있는 특정 상품을 클릭하면 상품 상세 페이지로 이동
- 상품 상세 페이지에서 해당 상품에 관한 세부적인 내용을 확인 할 수 있음

#### 미인증 사용자

- 상품 목록 조회 가능, 상품 상세 조회 가능

# 주문

- 주문관련 기능은 인증된 사용자만 사용 가능

### 장바구니 상품 주문

- 장바구니 화면에 있는 주문하기 버튼을 눌러 주문 페이지로 이동한다.
- 장바구니에 있는 상품들이 자동으로 주문하기 페이지에서 입력된다.
- 주문을 위해 필요한 정보를 입력하고 주문하기 버튼을 눌러 상품을 주문한다.

### 상품 상세 내역에서 상품 주문

- 특정 상품 상세 페이지에서 각 상품을 주문하기 위한 버튼이 있다.
- 해당 버튼을 누르면 해당 상품이 자동으로 입력된 주문하기 페이지로 이동된다.
- 주문하기 페이지에서 필요한 정보를 입력하거나 수정하고 주문하기 버튼을 눌러 상품을 주문한다.

### 주문 내역 조회

- 로그인 시 네비게이션 바에 주문 내역 버튼이 보이며, 해당 버튼을 누르면 주문 내역 페이지로 이동한다.
- 주문 내역 페이지에는 최신순으로 과거 주문 했던 내역의 목록을 확인 할 수 있다.

### 주문 상세 조회

- 주문 내역 페이지에서 특정 주문을 클릭하면 해당 주문에 대한 상세 내역이 있는 페이지로 이동한다.

### 주문 취소

- 특정 주문의 상세 내역 조회 페이지에 주문 취소 버튼이 있으며, 해당 버튼을 눌러 주문 취소가 가능하다.

# 장바구니

- 장바구니 기능은 인증된 사용자만 사용 가능

### 장바구니 상품 담기

- 상품 상세 내역 페이지에서 장바구니 담기 버튼이 있다.
- 장바구니 담기 버튼을 누르면 해당 상품이 장바구니에 담긴다.
- 상품 상세 내역 페이지에서 장바구니 담기 버튼을 누를 때 해당 상품 몇 개를 장바구니에 담을 지 설정할 수 있다.

### 장바구니 목록 조회

- 네비게이션 바에 장바구니 버튼이 있으며 해당 버튼을 누르면 장바구니 목록 화면으로 이동한다.
- 장바구니 목록 화면에는 장바구니에 담긴 여러 상품 목록을 확인할 수 있다.

### 장바구니 상품 수량 변경

- 장바구니 목록 화면에 각 상품이 몇 개 담겨 있는 지 확인할 수 있는 데 해당 숫자 옆에 버튼을 통해 장바구니에 담을 상품 수량을 조절할 수 있다.

### 장바구니 상품 삭제

- 장바구니 목록 화면에 각 상품에 따라 삭제 버튼이 있고, 해당 버튼을 누르면 해당 상품을 장바구니 목록에서 삭제 할 수 있다.
