# 프로젝트 개요

# 1. 프로젝트 목표

- 회원, 상품, 주문, 장바구니 도메인에 관한 기능이 있는 온라인 쇼핑몰 만들기

*초기에는 핵심 도메인 관련 기능만 구현하고, 추후에 기능 추가 예정

# 2. 기술 스택

- Spring, SpringBoot, Java, JPA, Spring Data JPA, MySQL, HTML, CSS, Bootstrap, Thymeleaf

# 3. 참여 인원

- 1인 (본인)

# 4. 배경

- 여러 도메인과 엔티티가 있는 프로젝트를 진행함으로써 비교적 복잡한 구조를 가진 웹 애플리케이션을 만들어보기 위함

# 5. 주요 기능

- 회원 가입과 로그인/로그아웃 기능
- 상품 등록/수정/삭제 (관리자)와 조회
- 여러 상품을 장바구니에 담을 수 있으며 수량 조절, 삭제 기능
- 장바구니에 담긴 상품 한꺼번에 주문과 특정 상품을 개별적으로 주문 기능
